# 示範準備度與資料完整性

`npm run demo:check` 在部署前驗證公開快照。條件包括 schema v4 以上、產生時間、觀察與歷史欄位、方法版本，以及每個追蹤標的（NBIS、CRWV、ORCL、AVGO）至少 60 筆近期、具日期且為正值的收盤價。標為 `ok` 的來源不可回報零筆可用資料；事件來源例外，零筆已驗證事件是有效結果。選用來源降級會顯示警示；快照超過 96 小時亦會警示。

新版公司訊號只以十筆有來源的收盤價計算 MA5/MA10。基本面、曝險、情緒、可信度、估值及區域容量數值在具備有來源的方法前均無資料。舊版 v1 歷史重建不再要求或公布。純價格回測是獨立的回溯分析，不代表可作投資決策。

事件來源有獨立狀態。人工審查檔案可顯示實際 `checkedAt`、審查範圍及 `coverageThrough`；不表示已搜尋所有可能來源。後續較新的自動事件檢查會取代顯示狀態，先前已驗證事件仍保留。
