# 評分方法論（原型）

分數是可解釋、具決定性的指標，並非投資建議。介面目前使用明確標示的示範觀察值，等待正式資料擷取。

擴張指數（0–100）由容量動能（35%）、公司投資（25%）、電網就緒度（20%）與專案進度（20%）組成。阻力指數由延遲／取消／拒絕 MW（35%）、電網連接摩擦（25%）、法規行動（20%）與環境／社區／融資摩擦（20%）組成。事件依專案階段、受影響 MW、確認機率與來源品質加權。

## 產品論點：預期落差，而非買賣分數

Gridline 不將文章情緒或單一建議混為一談，而是分開四個層次：

1. **資料中心需求**：客戶承諾、RPO／積壓訂單及需求趨勢。
2. **實體可交付性**：MW 分別追蹤公告、核准、供電確保、施工中與營運；這些是屬性，非保證的線性順序。
3. **公司執行力**：融資、資本支出、客戶集中度、交付時程及營運里程碑。
4. **市場預期**：市場情緒、估值，以及股價已內含的成長假設。

預期落差以第一至第三層對照第四層，可指出可能的正向錯價、預期偏高、基本面惡化或高度不確定性；絕非買賣指令。

此架構反映了公司揭露的容量階段差異：Nebius 分別揭露 contracted、connected 與 active power；Oracle 也在 OCI 成長之外揭露已交付資料中心 MW。法規也不應自動歸為利多或利空：FERC 的大型負載行動同時追求加速接入與消費者、可靠度保障。參考 [Nebius Q4 update](https://assets.nebius.com/assets/e59fb92e-9027-473a-8cac-04f9d2e9ea9a/Shareholder%20Letter%20Q4%202025.pdf?cache-buster=2026-02-12T11%3A43%3A13.446Z)、[Oracle Q1 FY27 results](https://investor.oracle.com/investor-news/news-details/2026/Oracle-Announces-Q1-Results-Driven-by-Triple-Digit-Growth-in-Cloud-Infrastructure-Revenues/default.aspx) 與 [FERC 大型負載行動](https://www.ferc.gov/news-events/news/ferc-launches-aggressive-targeted-action-speed-large-load-integration)。
